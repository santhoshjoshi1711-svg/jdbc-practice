# JDBC Practice

My Advanced Java JDBC practice programs using Oracle Database.

## Topics Covered

1. JDBC Connection
2. Statement
3. PreparedStatement
4. ResultSet
5. CRUD Operations
6. Batch Processing
7. CallableStatement

## Technologies

- Java
- JDBC
- Oracle Database

## Important

The examples use:

- Username: `oracle`
- Password: `YOUR_PASSWORD`

Replace `YOUR_PASSWORD` with your local Oracle password when running the programs.

Do not commit a real database password to a public GitHub repository.

## JDBC Driver

Oracle JDBC driver is required to run these programs.
